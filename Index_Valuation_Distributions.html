Index Valuation Distributions

Date: 2025-08-31

This report plots, for each index in each cluster, two distributions:

  1. Full history up to month-end (winsorized at the 5–95 percentiles),
  2. Last 10 years (winsorized at the 10–90 percentiles), drawn slightly to the right.

The red diamond marks the latest observation in the current month (or the last available value on/before month-end).

Winsorization caps extremes to reduce distortion from outliers (e.g., when earnings approach zero). Boxes show quartiles and median.

Box plot notes

  • Q1 (first quartile): value below which 25% of data fall.
  • Q3 (third quartile): value below which 75% of data fall.
  • Whiskers: lowest and highest values within 1.5×IQR (interquartile range).
  • N: number of valid (non-missing) observations.
